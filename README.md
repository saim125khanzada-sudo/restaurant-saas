# Multi-Tenant Restaurant Management SaaS Platform

A production-grade, cloud-hosted, multi-tenant Restaurant Management SaaS platform built for multi-branch restaurants.

## Technology Stack
- **Backend:** ASP.NET Core Web API, C#, .NET 10 LTS-compatible architecture
- **Database & Cache:** PostgreSQL 16+, Redis 7+, Entity Framework Core
- **Web Applications:** Next.js 15+, React, TypeScript, Tailwind CSS
- **Mobile Applications:** Flutter (Android Waiter & Rider apps)
- **Real-Time:** ASP.NET Core SignalR
- **Push Notifications:** Firebase Cloud Messaging (FCM HTTP v1)
- **POS Offline Mode:** Client-side SQLite + Outbox sync engine
- **Maps:** Google Maps Platform
